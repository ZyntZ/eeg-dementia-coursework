# Анализ ЭЭГ при нейродегенеративных заболеваниях с использованием МО
**Вопрос:** Насколько меняется результат классификации при переходе от записи с закрытыми глазами (ГЗ, ds004504) к записи с открытыми глазами + фотостимуляция (ГО, ds006036)? Не завышает ли оценка на другой записи знакомого человека качество модели?

**Данные:** OpenNeuro ds004504 (EC) + ds006036 (EO+фотостимуляция) — 88 человек (36 БА, 23 ЛВД, 29 Контроль), 500 Гц, 19 каналов 10-20. Разметка ГО есть у 87/88.

**План в 2 этапа (согласовано):**
1. Этап 1 — простая 3-классовая лог.регрессия с L2 по спектральным признакам (БА/ЛВД/Контроль). Обучение только на ГЗ обучающих, тест — парно на новых людях в двух условиях + доп. проверка на ГО обучающих.
2. Этап 2 — дообучение LEAD (https://github.com/DL4mHealth/LEAD) на всех 3 группах, если хватит ресурсов. Не тестировать модель только-БА на ЛВД.

**Протокол без утечки:** деление по людям, обе записи тестового человека вне обучения. Метрики по людям с bootstrap 95% CI.

## Быстрый старт
```bash
pip install -r requirements.txt
# скачать данные (требует openneuro CLI, ~1GB + 1.05GB)
openneuro download --dataset ds004504 --target-dir data/raw/ds004504
openneuro download --dataset ds006036 --target-dir data/raw/ds006036
python src/01_check_overlap.py
python src/02_features.py
python src/03_train_eval.py --config configs/split_stratified.json
```

## Воспроизводимость
- Версии наборов зафиксированы: ds004504 v1.0.8, ds006036 v1.0.6 (31.03.2026)
- `random_state=42` везде
- Фиксированный порядок сеансов (ГЗ всегда первый) — ограничение интерпретации (не только глаза).
